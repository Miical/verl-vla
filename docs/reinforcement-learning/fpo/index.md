# FPO

FPO applies a PPO-style clipped objective to a flow-matching policy without
requiring an exact action likelihood. The current implementation follows the
vanilla FPO objective from
[`amazon-far/fpo-control`](https://github.com/amazon-far/fpo-control); FPO++ is
not enabled.
